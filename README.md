# Martha Allen — Portfolio

A responsive, accessible, build-free portfolio based on Martha Allen’s supplied résumé.

## Run locally

Open `index.html` in a browser, or serve this folder with any static HTTP server.

## GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, then **main** and **/ (root)**. Save. No build dependencies or secrets are required.

## Content

Edit `index.html` to update the experience, projects, dates, contact email, and styles. The ICERI presentation is marked upcoming as of October 2026. Project illustrations are schematic workflows, not screenshots of employer software. The original résumé and telephone number are not included in this public source.
